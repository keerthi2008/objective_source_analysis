# objective_source_analysis
objective source analysis with pivot, bar charts in excel
---
##Objective

The objective of this task is to analyze participants' savings objectives and the common information sources used for investment decisions using Excel.

##Dataset Features

The dataset includes the following fields:
Gender
Age
Investment Avenues
Mutual Funds
Equity Market
Debentures
Government Bonds
Fixed Deposit
Objective
Purpose
Duration
Investment Monitoring
Expectations
Savings Objectives
Reasons for choosing different investment options
Source of investment information

##Analysis Performed :

Used Pivot Tables to summarize participants' savings objectives.

Created a Donut Chart to visualize the distribution of savings objectives.

Used Pivot Tables to summarize the frequency of information sources.

Created a Horizontal Bar Chart to display the usage of different information sources.

##Tools Used
Microsoft Excel

##Outcome:

This analysis helps understand the primary goals behind participants' savings and the common sources they rely on for investment information.

##Files Included :

Excel file containing pivot tables and charts

Visualization charts for savings objectives and information sources
